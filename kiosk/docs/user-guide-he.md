# מדריך משתמש — הפעלת מכשיר קיוסק

מדריך זה מיועד ללקוח שקיבל **שם משתמש וסיסמה** למערכת KioskFleet ורוצה להעלות
טאבלט אנדרואיד כעמדת קיוסק נעולה, הנשלטת מרחוק.

---

## שלב 1 — כניסה למערכת הניהול

1. היכנסו לכתובת מערכת הניהול (למשל `https://panel.kioskfleet.com/console`).
2. הזינו את שם המשתמש והסיסמה שקיבלתם.
3. מומלץ מיד להיכנס ל**הגדרות ← שינוי סיסמה** ולהחליף לסיסמה אישית.

---

## שלב 2 — יצירת קוד רישום למכשיר

1. בתפריט הצד לחצו על **➕ הוספת מכשיר**.
2. מלאו:
   - **שם המכשיר** — לזיהוי בדשבורד (למשל "כניסה ראשית").
   - **כתובת האתר** — הכתובת המלאה שהמכשיר יציג (למשל `https://giftkal.com/kiosk`).
3. לחצו **צור קוד רישום**. יוצג קוד בן **6 תווים** (למשל `K7B2XQ`). רשמו אותו.

> כל קוד רישום תקף למכשיר אחד ולמשך 14 יום. מספר המכשירים מוגבל לפי המכסה בחשבונכם.

---

## שלב 3 — התקנת האפליקציה על הטאבלט

1. העבירו את הקובץ `kioskfleet-agent.apk` למכשיר (כבל USB, דיסק, או הורדה).
2. הריצו את הקובץ. אם מופיעה אזהרה **"התקנה ממקורות לא ידועים"**:
   - **הגדרות ← אבטחה ← מקורות לא ידועים** → אפשרו עבור מנהל הקבצים/הדפדפן.
3. סיימו את ההתקנה ופתחו את האפליקציה.

---

## שלב 4 — רישום המכשיר

במסך הפתיחה של האפליקציה:
1. **כתובת שרת הניהול** — הזינו את כתובת המערכת (למשל `https://panel.kioskfleet.com`).
2. **קוד רישום** — הזינו את הקוד בן 6 התווים משלב 2.
3. לחצו **רישום והפעלה**.

המכשיר יירשם, יטען את האתר שהוגדר, ותוך שניות יופיע בדשבורד תחת "המכשירים שלי"
עם נורית ירוקה (**מחובר**).

---

## שלב 5 (מומלץ מאוד) — נעילה הרמטית עם Device Owner

זה מה שחוסם לחלוטין את כפתורי **Home / Back / Recents** ומונע יציאה מהאפליקציה.
מבצעים **פעם אחת בלבד**, על מכשיר **מאופס וללא חשבון Google**.

### מה צריך
- מחשב עם כלי **ADB** (חלק מ‑Android Platform Tools).
- כבל USB.

### הצעדים
1. במכשיר: **הגדרות ← אודות הטלפון** → הקישו 7 פעמים על **מספר Build** כדי לפתוח
   "אפשרויות מפתח".
2. **הגדרות ← מערכת ← אפשרויות מפתח** → הפעילו **ניפוי באגים USB (USB Debugging)**.
3. חברו את המכשיר למחשב ואשרו את חלון האמון.
4. במחשב הריצו:
   ```bash
   adb shell dpm set-device-owner com.kioskfleet.agent/.KioskDeviceAdminReceiver
   ```
   תוצאה תקינה:
   ```
   Success: Device owner set to package com.kioskfleet.agent
   ```

> ⚠️ אם מתקבלת שגיאה — המכשיר אינו נקי. בצעו **איפוס להגדרות יצרן**, דלגו על
> הוספת חשבון Google, והתקינו מחדש לפני הרצת הפקודה.

---

## שלב 6 — הגדרות מומלצות במכשיר

- **מסך תמיד דלוק:** הגדרות ← תצוגה ← מצב שינה ← **לעולם לא**.
- **ביטול עדכונים אוטומטיים:** הגדרות ← מערכת ← עדכון מערכת ← כבו.
- **ריצה חופשית ברקע:** הגדרות ← אפליקציות ← KioskFleet ← סוללה ← **ללא הגבלה**.
- **נעילת ADB לאחר ההגדרה** (אבטחה): לאחר שסיימתם, כבו את "ניפוי באגים USB".

---

## שליטה מרחוק — מה אפשר לעשות מהדשבורד

לכל מכשיר יש כפתורים בדשבורד:

| פעולה | מה קורה |
|-------|---------|
| 🔄 רענן | טוען מחדש את העמוד הנוכחי |
| 🔗 החלף אתר | מעביר את המכשיר לכתובת אחרת (בתוך הדומיין המורשה) |
| ♻️ אתחל | מאתחל את המכשיר (דורש Device Owner) |
| 🌙 כבה מסך | מחשיך את המסך לחיסכון |
| ☀️ הדלק מסך | מחזיר את התצוגה |
| 🧹 נקה מטמון | מנקה את זיכרון הדפדפן |
| ✏️ עריכה | שינוי שם / כתובת בית / דומיין מורשה |

הפקודות מגיעות למכשיר **מיידית** כשהוא מחובר, או ממתינות בתור ומבוצעות ברגע
שהמכשיר חוזר להיות מקוון.

---

## תחזוקה מקומית (במכשיר עצמו)

- **כניסה ידנית:** 5 נגיעות רצופות בפינה השמאלית‑העליונה של המסך, ואז הזנת קוד
  התחזוקה המקומי (אם הוגדר).
- **פתיחה מרחוק:** שלחו פקודת **פתיחה (unlock)** מהדשבורד — המכשיר ייפתח לתחזוקה
  לזמן מוגבל ואז יינעל אוטומטית מחדש.

## שאלות נפוצות

**המכשיר מופיע "מנותק" — מה לעשות?**
ודאו חיבור אינטרנט; שהאפליקציה מוגדרת "סוללה ללא הגבלה"; ושכתובת השרת נכונה.

**החלפתי אתר וזה לא קורה?**
כתובת חדשה חייבת להיות תחת אותו דומיין מורשה. לשינוי דומיין השתמשו ב‑✏️ עריכה.

**שכחתי סיסמה למערכת?**
פנו למנהל‑העל — הוא יכול לאפס לכם סיסמה.
