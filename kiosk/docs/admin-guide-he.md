# מדריך מנהל‑על (Super Admin)

מנהל‑העל מנהל את כל הלקוחות והצי כולו. חשבון מנהל‑העל הראשון נוצר אוטומטית
בהפעלה הראשונה של השרת (ראו `docs/deployment.md`).

## התחברות
היכנסו ל‑`/console` עם פרטי מנהל‑העל. בתפריט יופיע פריט נוסף: **👑 ניהול‑על**.
**החליפו את סיסמת ברירת המחדל מיד** דרך ⚙️ הגדרות.

## מסך ניהול‑העל

### סטטיסטיקות
מספר הלקוחות, סך המכשירים, כמה מחוברים כעת וכמה מנותקים — בזמן אמת.

### ניהול לקוחות
- **➕ לקוח חדש** — יצירת חשבון: שם משתמש, סיסמה (8+ תווים), שם מלא ו**מכסת מכשירים**.
- **ערוך** — שינוי שם, מכסה, והפעלה/השבתה של החשבון.
- **סיסמה** — איפוס סיסמה ללקוח.
- **מחק** — מחיקת לקוח (כל מכשיריו יימחקו).

### מכסת מכשירים
המכסה קובעת כמה מכשירים + קודי רישום פתוחים מותרים ללקוח בו‑זמנית. הגדלת המכסה
מאפשרת ללקוח לרשום מכשירים נוספים מיד.

## צפייה בכל הצי
מסך **🖥️ המכשירים שלי** של מנהל‑העל מציג את **כל** המכשירים בכל החשבונות (עם שם
הלקוח לכל מכשיר), וכל פקודות השליטה מרחוק זמינות עליהם.

## אבטחת המערכת — המלצות
1. הריצו את השרת **מאחורי HTTPS** בלבד (ראו deployment). ה‑WebSocket יעבור אוטומטית ל‑`wss://`.
2. הגדירו `JWT_SECRET` ארוך ואקראי, ושמרו אותו ב‑secret store (לא ב‑git).
3. החליפו את סיסמת מנהל‑העל הראשונית מיד.
4. תנו לכל לקוח מכסה מדויקת — כך אף אחד לא יכול לרשום מכשירים מעבר למותר.
5. גבו את קובץ מסד הנתונים (`data/kioskfleet.db`) באופן קבוע.
